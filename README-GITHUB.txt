建築資源循環ラボ：GitHub Pages更新用ファイル
2026年11月9日版

公開先： https://fujisan09.github.io/circular-building-lab/
リポジトリ： https://github.com/fujisan09/circular-building-lab

1. ZIPを展開します。
2. GitHubリポジトリのCode → Add file → Upload filesを開きます。
3. index.html、assets、market、scan、privacyを、フォルダー構成を保ってルートへドラッグします。
   ZIPファイルそのものや、一段上の親フォルダーを置く形ではありません。
4. Commit changesでmainに反映します。
5. Settings → Pages → Deploy from a branch / main / (root) を確認します。
6. GitHub Pagesの公開処理が完了したら、公開URLを開いて確認します。

追加ページ： market/ と scan/
保存候補と出品プレビューは同じブラウザーだけに保存します。公開在庫・決済・AI抽出はありません。
PLY読込は先頭最大1MBのヘッダー情報確認です。実ファイルの品目抽出はPC版ScanDeskの開発範囲です。

Facebook用のタイトル・説明・画像のメタ情報を設定済みです。表示内容はFacebook側の再取得状況にも依存します。
GitHub向けのcanonical / og:url / og:imageは上記公開先に調整済みです。

本ファイルと同梱のREADMEは公開に必須ではありません。
既存GitHubリポジトリへの更新は、ZIPをアップロードするかGitHub接続後に実行する必要があります。
